# Examples

Per-action sketches for the beliq Pipedream connector. Each describes the trigger,
the beliq step, and what the following steps receive.

- [validate-incoming-invoice.md](./validate-incoming-invoice.md): validate an
  invoice attached to an inbound email or webhook.
- [generate-invoice-pdf.md](./generate-invoice-pdf.md): turn structured invoice
  data into a hybrid PDF/A-3 e-invoice.
- [convert-format.md](./convert-format.md): convert a received invoice from one
  EN 16931 format to another.
